# EcoTrack — Responsive Landing Page

Landing page responsiva para um produto fictício de acompanhamento de indicadores ambientais. O projeto foca em HTML semântico, CSS moderno, acessibilidade e layout adaptável a telas pequenas.

## Como visualizar
Abra `index.html` no navegador. Não há build, bibliotecas ou dependências externas.

## Destaques
- HTML5 semântico e navegação por âncoras.
- Layout responsivo com CSS Grid e Flexbox.
- Estados de foco visíveis, contraste e respeito a `prefers-reduced-motion`.
- Componentes reutilizáveis via classes CSS e organização por seções.
